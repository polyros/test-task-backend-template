## Легенда

Вы присоединились к команде разработки платформы прогнозов (prediction markets). Junior-разработчик написал модуль управления пользователями и ушёл в отпуск. Код уже в `main` ветке, но ещё не задеплоен в production.

Ваша задача - провести code review, найти проблемы и исправить их до релиза.

## Задание

### 1. Code Review (REVIEW.md)

Изучите код в `app/` и заполните файл `REVIEW.md`:
- Найдите и опишите проблемы в коде
- Укажите потенциальные последствия каждой проблемы
- Предложите способы исправления

### 2. Исправление кода

- Исправьте найденные проблемы
- Сохраните функциональность (API должен работать так же)
- Следуйте best practices Python/FastAPI

### 3. Тесты

- Напишите минимум 3 теста в `tests/`
- Покройте критичные сценарии
- Тесты должны проходить: `pytest tests/`

## Запуск проекта

```bash
# Установка зависимостей
pip install -e ".[dev]"

# Запуск сервера
uvicorn app.main:app --reload

# Запуск тестов
pytest tests/ -v
```

### Docker (альтернатива)

```bash
docker build -t test-task .
docker run -p 8000:8000 test-task
```

## Ограничения

- **Время:** 3 часа
- **Инструменты:** IDE, документация, Google, Stack Overflow

### ВАЖНО: Запрет на AI для Code Review

**REVIEW.md должен быть написан вами лично, без использования AI-ассистентов (ChatGPT, Claude, Copilot Chat и т.д.).**

Мы проверяем именно ваши навыки анализа кода и умение находить проблемы. AI-сгенерированные ревью легко распознаются и приводят к автоматическому отклонению.

Для написания кода (исправления, тесты) AI-инструменты допустимы, но будьте готовы объяснить каждое решение на собеседовании.

## Критерии оценки

- Полнота найденных проблем
- Качество описания проблем и их последствий
- Корректность исправлений
- Качество и полнота тестов
- Чистота и читаемость кода
